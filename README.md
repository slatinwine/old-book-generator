# 旧书图文生成器

单文件 HTML 小工具：把一段文字排成"旧书"风格的图片。

- 第一行 = 封面大字标题，其余行 = 内页正文（一段一行，段落尽量不拆页）
- 只输一行时全部按封面大字处理，自动分页
- 字体风格可切（黏连 / 清晰），内页每页字数可调
- 生成 1242×1660 图片，可单页或批量导出 PNG

纯前端、无构建、无后端，整站就一个 `index.html`（旧书纸纹背景内嵌）。

**在线使用**：<https://slatinwine.github.io/old-book-generator/>

## 本地运行

直接双击 `index.html` 用浏览器打开即可；或

```bash
python -m http.server 8123
# 打开 http://localhost:8123
```

> 中文字体走 Google Fonts，同时加载了 loli.net 国内镜像，任一可用即可。
